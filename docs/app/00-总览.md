# 00 · 总览：这个 APK 做了什么

> 描述对象：`app/build/math-coach-arm64-v8a.apk`
> 包名 `com.mathcoach.app` · 版本 `1.0.0+1` · Android 7.0（API 24）起可用

---

## 1. 身份卡

| 项目 | 值 | 说明 |
|---|---|---|
| 包名 | `com.mathcoach.app` | |
| minSdk / targetSdk | 24 / 34 | 覆盖 Android 7.0 及以上 |
| **申请的权限** | **无（0 条）** | 不是"少用权限"，是一条都没有 |
| CPU 架构 | arm64-v8a | 只含这一种 `.so` |
| 体积 | **约 26 MB** | 已用 NDK `llvm-strip` 剥掉引擎调试符号（原 172 MB） |
| 运行时后端 | Impeller | Flutter 3.47 |
| 网络 | 完全不使用 | 无 `INTERNET` 权限，物理上发不出请求 |

体积是怎么下来的：SDK 自带的 `libflutter.so` 是未 strip 的 release 产物，
157 MB 里有 146 MB 是 `.debug_*` / `.symtab` —— 给调试器看的，装到手机上没用。
构建脚本现在会先复制再剥（绝不原地改 SDK 缓存里的产物），需要带符号排查
native 崩溃时用 `--no-strip` 重新构建即可。

## 3. 数据是怎么流动的

```
① 出题     QuizGenerator.generateMany(grade, unit, count)
           └─ 从 23 个题型工厂里按年级/知识点筛 → 随机抽 → 逐题过正确性闸门
                                                          ↓ 不合格就重抽，最多 60 次
② 渲染     题卡拿到的不是图，是"参数"：
             figureSpec   （几何语义 DSL：什么图形、多长、要不要涂色）
             verticalKind + verticalArgs（竖式的种类和参与运算的数）
           └─ 运行时由 FigureSolver 算出坐标 → CustomPainter 画到 Canvas
③ 作答     每道题一个 TextEditingController（提到页面层持有，键盘弹出不丢字）
④ 判分     QuizAnswer.check(input)：有理数精确比对，容忍 "0.5"/".5"/"0.50"
⑤ 归档     repo.recordAttempt：更新 FSRS 状态 + 重要度 → 写 wrongbook.json
⑥ 复习     repo.dueQueue(now)：只挑 due <= now 的，重要度高的排前面
⑦ 导出     PaperPdfExporter：figureSpec 按 PDF 精度重新求解 → 真矢量，A4
```

关键在第 ② 步：**存档里没有图片，只有参数**。所以同一道题在手机屏幕上是清晰的，
导出到 A4 纸上还是清晰的 —— 因为两条路都是"重新算坐标再画"，而不是"把屏幕截图放大"。

## 4. 三条不妥协的规矩

这套东西的价值全在这三条上，代码里到处是对应的注释：

**① 答案必须本地算，模型不参与给数。**
所有数值走 `Rational`（`BigInt` 分子分母，自动约分），不用 `double`。
理由写在 `lib/core/rational.dart` 开头：`0.1 + 0.2` 这类浮点误差会让"本地算的"和
"模型给的"对不上，而对不上就无法校验。小学题的数字都很小，精确计算完全负担得起。

**② 每道题都要过正确性闸门。**
随机不等于随便。闸门拦截这几类退化题：减法出负数、除法除不尽或余数 ≥ 除数、
三角形三边不成三角形、组合图形面积为零、多边形自交。
见 `lib/variant/generator.dart` 的 `VariantGate`。

**③ 讲解要像老师说话，不是算式罗列。**
例如有余数除法的讲解是：

> 想：7 乘几最接近 58 又不超过它？7 × 8 = 56。
> 58 减 56 得 2。
> 余数 2 比除数 7 小，说明试对了。
> 结果是 8 余 2。

## 5. 依赖情况

| 层 | 依赖 |
|---|---|
| Dart 内核 | 无三方包（除 PDF 场景的 `pdf` 包） |
| Flutter UI | 无三方插件，`pubspec.yaml` 只依赖 `flutter` + 内核 |
| Android 原生 | Flutter embedding + 必需的 androidx（lifecycle / core / activity / fragment / tracing / window）+ ReLinker + kotlin-stdlib |

**注意**：`pubspec.yaml` 里没有 `shared_preferences`、`path_provider`、`share_plus` 这些常见插件。
数据目录是通过一个 `MethodChannel('mathcoach/storage')` 从 `MainActivity` 拿的，
分享也是同一个通道。好处是 dex 干净、没有插件注册失败的风险；
代价是这些能力都得自己写少量 Java 代码。

## 6. 相对于原始方案：做了什么、没做什么

原始方案描述的是「拍照 → 识题 → AI 答案 + 分步 → 知识点归类 → 错题归档 → 变体闯关 → 导出 PDF」的完整链路。
**这条链路现在已经全通了。**

| 方案中的环节 | 状态 | 当前实现 |
|---|---|---|
| 拍照 | ✅ 已实现 | **从系统相册选图**（`ACTION_GET_CONTENT`），不是直接调相机 —— 这样不用申请 `CAMERA` 权限 |
| 图像识别成题 | ✅ 已实现 | 云端视觉模型（`lib/ai/ocr.dart`），**一图多题 ≤8 道**按题分卡；主模型挂了自动降级一次备胎 |
| AI 给答案和分步讲解 | ✅ **两条路径** | 拍照来的题走大模型（`KidSolver`，≥2 步闸门 + 答案本地复算）；本地题库的题仍用模板 —— 见下方说明 |
| 知识点归类 | ✅ 已实现 | 三级编码 `MA-G3-S1-NA-03-02`，人教版 1–6 年级 |
| 错题归档 | ✅ 已实现 | 自动，提交批改时写入 |
| 变体闯关 | ✅ 已实现 | 错题本每条记录旁有「闯关」按钮，页首还有「变体闯关」（取最重要的 3 题）——同类题换数字，答案本地算，答错自动归档 |
| 导出 PDF | ✅ 已实现 | A4、矢量图、内嵌中文字体 |
| 复习调度 | ✅ 已实现 | **真 FSRS-6**（21 参数，与官方 py-fsrs 逐条数值对照），不是简化版 |
| 数据备份 | ✅ 已实现 | 设置 → 数据：导出带时间戳 JSON（系统分享送出）；导入走系统文件选择器并与现有记录合并。卸载 App 前务必导一份 |

**关于权限，说准确**：APK 的 `AndroidManifest.xml` 里**只有一条** `INTERNET`。
拍照那条路走的是「系统相册选图」而不是自己调相机 —— 由相册 App 拿图、回传路径，
所以不需要 `CAMERA` 权限。代价是家长得先把作业拍下来（存进相册）再选，
比"直接拍"多一步；换来的是权限清单干净。

**为什么本地题库的讲解故意留着模板**：模型给的讲解没法本地校验对错，
而模板讲解和答案是**同一份代码从同一组数字算出来的**，两者必然一致。
对小学生来说「讲解和答案对不上」是最致命的 —— 那不是讲得差，是讲错了。
拍照来的题没有本地模板可用，才走模型，且必须过验算那道闸（三态：
exact / unverifiable / mismatch）。

## 7. 怎么构建

```bash
cd math_coach/app
python tool/fetch_androidx.py            # 首次：递归解析并下载 androidx 依赖
python tool/build_apk.py --abi arm64-v8a # 产物 build/math-coach-arm64-v8a.apk
```

这条链路是**手工编排的**，不走 `flutter build apk`。原因是本机 Dart 无法通过管道
启动子进程（`CreateFile failed 231`），`flutter` 工具链和 Gradle 都用不了。
流水线步骤：`frontend_server → app.dill → gen_snapshot → libapp.so → javac + d8 → classes.dex → aapt2 link → 打包 → zipalign + apksigner`。

> ⚠️ **签名注意**：首次构建会生成 `build/debug.keystore`。如果删掉 `build/` 目录重新构建，
> keystore 会重新生成，签名就变了 —— 手机上装了旧版会导致**覆盖安装失败**。
> 解决办法：先卸载旧版再装，或者把 `debug.keystore` 备份出去复用。

## 9. 已知边界

1. **体积约 26 MB**（已 strip；`--no-strip` 出的带符号包约 172 MB）。
2. **只支持 arm64-v8a**。32 位老设备装不了（可加 `--abi armeabi-v7a` 构建）。
3. **锁竖屏**（几何题和竖式在横屏下会被压扁）。
4. **变体闯关**覆盖 9 类题型；立体图形、展开图这类还没有变体模板，闯关页会说明原因。
5. 数据存在 App 专属目录，**卸载 App 会丢失**。备份走设置 → 数据 → 导出 JSON；PDF 导出是练习卷不是备份。
6. `debug.keystore` 是调试签名，不能上架应用商店（上架需换成正式签名）。
7. strip 后的崩溃栈没有 native 符号；排查 native 崩溃用 `--no-strip` 出一版带符号的。
