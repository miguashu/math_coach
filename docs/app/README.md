## 一句话版本

一个**离线可用**的小学数学（1–6 年级）练习工具：题目在手机上随机生成，答案和几何坐标
在手机上精确算出，做错的题自动进错题本并按间隔重复出现，随时可以把错题导出成能打印的 A4 练习卷。
联网后多三块能力 —— 拍照识题、分步讲解（见 `08-联网AI与实测.md`），
以及**拍照判卷 + 为判错的题自动衍生同类练习题**（进「错题本 → 衍生题库」，见 `03-错题本页.md`）。

## 文档里怎么区分「已实现」和「没实现」

- ✅ **已实现**：代码里有，且构建产物里能验到。
- ⚠️ **部分实现**：代码里有但存在边界，文档会写清楚边界在哪。
- ❌ **未实现**：原始方案里提到过，但当前 APK 中没有对应代码。写进文档是为了避免误判，
  不是待办清单。
