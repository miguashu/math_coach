# 06 · 数据模型与本地存储

> 源码：`app/lib/state.dart`、`lib/store/repository.dart`、`lib/review/fsrs.dart`、`lib/knowledge/`

这一篇讲「孩子的错题记在手机里的什么地方、以什么形式保存」，以及复习时间是怎么算出来的。

---

## 1. 存什么：题目参数，不是渲染结果

这是整个存储设计里最关键的一条决定。

一条错题记录（`ReviewRecord`）里，**没有图片、没有 SVG 字符串**，只有：

| 字段 | 存的是什么 | 为什么不存结果 |
|---|---|---|
| `stem` | 题干文本 | 文本本身就是结果 |
| `answer` / `steps` | 答案文本 + 分步讲解 | 同上 |
| `figureSpec` | 几何的**语义描述**（什么图形、多长、要不要涂色） | 存坐标就锁死在生成时的尺寸，导出 A4 就会糊 |
| `verticalKind` + `verticalArgs` | 竖式的**种类 + 参与运算的数**（如 `['mul', 23, 45]`） | 存图就没法按 PDF 排版器重画了 |

**收益**：

1. 导出 PDF 时图形是按打印精度**重新求解**的，打印出来和屏幕上一样清楚；
2. 记录文件小（一条几百字节，几百条记录也就几十 KB）；
3. 换屏幕尺寸 / 换系统字体，图形自动适配，不会错位。

代价是**每次显示都要重新算一次坐标**。对小学几何题这个量级完全无所谓
（`FigureSolver.solve` 是纯 Dart 的几十行到几百行算术）。

## 2. 一条记录长什么样

```json
{
  "id": "div-58-7",
  "kind": "divRem",
  "stem": "用竖式算一算：58 ÷ 7 =",
  "grade": 3,
  "kpPath": "数与代数 / 有余数的除法 / 余数比除数小",
  "kpCode": "MA-G3-S1-NA-04-02",
  "difficulty": 2,
  "answer": "8 …… 2",
  "steps": [
    "想：7 乘几最接近 58 又不超过它？7 × 8 = 56。",
    "58 减 56 得 2。",
    "余数 2 比除数 7 小，说明试对了。",
    "结果是 8 余 2。"
  ],
  "verticalKind": "div",
  "verticalArgs": [58, 7],
  "fsrs": {
    "stability": 3.0,
    "difficulty": 5.0,
    "due": 1760342400000,
    "reps": 1,
    "lapses": 0
  },
  "importance": 1,
  "streak": 0,
  "wrongCount": 1,
  "rightCount": 0,
  "createdAt": 1760256000000,
  "lastSeen": 1760256000000
}
```

### 字段说明

| 字段 | 类型 | 含义 |
|---|---|---|
| `id` | String | 稳定 id，同参数同 id，用于去重 |
| `kind` | String | 题型标识（`add` / `sub` / `mul` / `divRem` / `rect` / …） |
| `stem` | String | 题干 |
| `grade` | int | 年级 1–6 |
| `kpPath` | String | 知识点路径（领域 / 单元 / 考点） |
| `kpCode` | String? | 三级知识编码 |
| `difficulty` | int | 难度 1–5 |
| `answer` | String | 正确答案展示文本 |
| `steps` | List\<String\> | 分步讲解 |
| `figureSpec` | Map? | 几何语义 spec |
| `verticalKind` / `verticalArgs` | String? / List\<int\> | 竖式重放参数 |
| `fsrs` | Map | 复习调度状态 |
| `importance` | int | 重要度 0–10 |
| `streak` | int | 连续答对次数 |
| `wrongCount` / `rightCount` | int | 累计错 / 对次数 |
| `createdAt` / `lastSeen` | int | 首次收录 / 最近作答（毫秒时间戳） |

## 3. 存在哪里

```
<App 外部专属目录>/math_coach/
├── wrongbook.json          # 错题本（一条 = 一道做错过的原题，带 FSRS 状态）
├── bank.json               # 衍生题库（一条 = 为某道错题造的练习题，只有"过关没"）
├── recent_stems.json       # 最近 40 条题干（给 AI 出题做避重）
├── ai_config.json          # AI 配置（含 key，不进仓库、不上传）
├── activity_log.jsonl      # 运行记录（上限 500 条）
└── *.pdf                   # 导出的练习卷
```

实际路径通常形如：

```
/storage/emulated/0/Android/data/com.mathcoach.app/files/math_coach/wrongbook.json
```

**为什么放外部专属目录**：手机自带的「文件」App 能直接找到，
导出的 PDF 可以拷到电脑、发微信、连打印机。

目录由 `MainActivity` 通过 `MethodChannel('mathcoach/storage')` 的 `filesDir` 方法提供，
拿不到外部存储时自动退回内部目录。

### 为什么题库要和错题本分两个文件

| | 错题本 | 衍生题库 |
|---|---|---|
| 一条代表 | 一道**孩子做错过的原题** | 为某道错题**造出来的练习题** |
| 有 FSRS 状态 | 有（决定什么时候复习） | 没有（只记"练过没、过没过"） |
| 有重要度 | 有（决定在清单里排多前） | 没有 |
| 参与统计 | 是（"要重点看 3 道"） | 只在题库段内统计 |

混在一起的话，练习题会把错题本的重要度统计稀释掉 ——
而那个统计是家长唯一的决策依据。

### 题库记录的关键字段

```dart
class BankEntry {
  final String id;              // 'dv-<题干 FNV-1a>'，同题天然去重
  final String sourceQuestionId; // 来源错题（回查 + 分组）
  final String sourceStem;      // 来源题干（"想不起来看原题"）
  final String stem, answer;
  final double? answerValue;    // 判分容差用
  final String origin;          // 'local'（本地模板）| 'ai'（模型出，过了本地验算）
  final int attempts, wrongCount, streak;
  final bool passed;            // 连对 2 次（BankEntry.passStreak）
}
```

> **id 为什么自己算 FNV-1a，不用 `String.hashCode`**：
> `hashCode` 只保证同一次运行内稳定，跨 Dart 版本/平台可能变；
> 一旦变了，升级后同一个题会被当成新题再入账一遍。

### 容错

```dart
Future<void> load() async {
  try {
    // 读文件 → jsonDecode → 逐条 fromMap
  } catch (e) {
    // 数据文件损坏不能让 App 起不来：备份后用空库继续
    await file.rename('${file.path}.broken-${…}');
  }
}
```

两处刻意的容错：

1. **文件损坏 → 重命名为 `.broken-时间戳` → 用空库继续**。绝不因为一个坏文件打不开 App。
2. **存储初始化失败 → 退回系统临时目录**，并在设置页显示错误提示。
   此时数据不会持久保存，但至少当次能用。

另外两处不入账的规矩：

- 题目的**题干**（规范化后）重复 → 不入账（同一道题反复生成不许堆成三份）；
- 题干或答案为空 → 不入账（残缺记录比没有记录更坏）。

## 4. 复习时间怎么算（FSRS）

`lib/review/fsrs.dart` 实现的是 FSRS 的核心思想：
**记忆稳定性 S、记忆难度 D、间隔 I = f(S, D, 评分)**。

### 状态

| 量 | 含义 |
|---|---|
| `stability`（S） | 记忆稳定性（天）。越大记得越牢 |
| `difficulty`（D） | 记忆难度 1–10。越大越难 |
| `due` | 下次复习时间 |
| `reps` | 已复习次数 |
| `lapses` | 遗忘（答错）次数 |

### 三条分支

```dart
if (reps == 0 && rating != again) {
    // ① 首次学习：按评分给初始稳定性
    newS = firstStability[i];        // [0.5, 1.0, 3.0, 7.0] 天
    newD = clamp(5 + (3 - value), 1, 10);
} else if (rating == again) {
    // ② 遗忘：稳定性砍到 35%，难度 +1.5
    newS = (S * 0.35).clamp(0.5, 180);
    newD = clamp(D + 1.5, 1, 10);
} else {
    // ③ 通过：按评分倍率增长，难度越高增长越慢
    factor = factors[i];             // [0.35, 1.2, 2.2, 3.2]
    newD = clamp(D + (3 - value) * 0.8, 1, 10);
    newS = S * factor * ((11 - newD) / 8.0);
    if (newS < S * 1.05) newS = S * 1.05;   // 保证答对一定有进展
}
```

### 两个非显然的设计

**① 第一次就答错，不走"首次学习"分支**

```dart
if (s.reps == 0 && r != Rating.again) { … }
else if (r == Rating.again) { … }   // ← 覆盖了 reps == 0 的情况
```

第一次答错就是"没学会"，不能按首次学习的间隔把它排到三天后去。

**② 答对至少涨 5%**

```dart
if (newS < s.stability * 1.05) newS = s.stability * 1.05;
```

难度很高时，FSRS 算出来的间隔可能比原来还短。
数学上没错，但**孩子会觉得"练了也没用"**，所以强行保底涨 5%。

### 答错之后：立刻回到队首

```dart
due: didForget ? now.add(config.lapseStep) : now.add(…)
//                       lapseStep = Duration.zero
```

**`lapseStep = Duration.zero`** —— 答错后 `due = now`，立即重新到期。

为什么不能用算出来的稳定间隔：

> 错题必须在几分钟内回来重练一次。
> 等到三天后再见，这段讲解早就忘干净了 —— 那样错题本就失去意义了。

## 5. 重要度：会衰减的优先度

```dart
class ImportancePolicy {
  final int wrongDelta    = 1;  // 答错 +1
  final int rightDecay    = 1;  // 答对 −1
  final int streakToClear = 3;  // 连续答对 3 次 → 归零
  final int max           = 10; // 上限
}
```

```
答错 → importance + 1，streak 归零
答对 → streak + 1
       streak >= 3 → importance = 0（毕业）
       否则        → importance − 1
```

**为什么重要度必须能衰减**：

- 单调累加会让「练了 20 次」的考点永远排在「错了 1 次但完全没掌握」的前面；
- 更重要的一层：清单会变成**耻辱墙**。孩子打开看到的永远是「我又欠了多少」，
  而不是「我攻克了什么」。

所以「什么时候该复习」交给 FSRS 管，「排多前」交给重要度管，两件事分开记。

## 6. 知识点编码

编码规则：`MA-G{年级}-S{学期}-{领域}-{单元号}-{考点号}`

```
MA-G3-S1-NA-04-02
│  │   │  │   │   └─ 第 2 个考点
│  │   │  │   └───── 第 4 个单元
│  │   │  └───────── 数与代数
│  │   └──────────── 上学期
│  └──────────────── 三年级
└─────────────────── Mathematics
```

领域代码：

| 代码 | 领域 |
|---|---|
| `NA` | 数与代数 |
| `GS` | 图形与几何 |
| `SP` | 统计与概率 |
| `IP` | 综合与实践 |
| `ET` | 数学广角 / 拓展 |

**一处必须交代的补全**：原始《小学数学 1–6 年级知识点分类表》只给了
「领域 + 单元/知识点 + 细粒度考点标签」，**没有学期字段**，
但编码里需要 S1/S2。这里按人教版教材目录补齐了学期与单元顺序。

种子数据覆盖 6 个年级、约 90 个单元、300+ 个叶子考点。

## 7. 已知边界

| 边界 | 说明 |
|---|---|
| 单文件 JSON | 每次作答**全量重写整个文件**。几百条记录没问题，上千条会有卡顿 |
| 无加密 | 明文存储。不过数据本来就在本地，且不联网 |
| 无备份 / 无同步 | 换手机 = 数据丢失（导出 PDF 是唯一出口） |
| 无版本迁移 | `version: 1` 字段已预留但未实现迁移逻辑，将来改结构需手动处理 |
| 卸载即删 | 存在 App 专属目录，卸载时系统会一并清除 |
| FSRS 参数未校准 | 用的是 FSRS 默认参数，未按真实学习数据调优 |
| 只记对错，不记过程 | 看不到"某次具体答了什么、花了多久" |
