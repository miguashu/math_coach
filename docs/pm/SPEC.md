## 0. 一句话

一个**离线可用**的小学 1–6 年级数学练习工具：题目在手机上生成，答案与几何坐标在手机上

拍照识题、分步讲解。

## 1. 目标 / 非目标

### 在范围内（In scope）

| # | 目标 | 验收口径 |
|---|---|---|
| G1 | 出题：按年级与知识点出一套题，覆盖 1–6 年级 | 23 个题型工厂，逐题过正确性闸门 |
| G2 | 判分：输入容错，"0.5" / ".5" / "0.50" 同判 | `QuizAnswer.check` 有理数精确比对 |

| G6 | 分步讲解：面向小学生、步骤完整 | ≥2 步，Agent 不合格会打回重做一次 |
| G7 | 同类题：简单本地生成，复杂模型生成 | 答案一律本地复算，不符丢弃 |
| G8 | 运行记录：给管理员看整体运行情况 | 调用统计 + 学习侧统计 + CSV 导出 |
| G9 | 变体闯关：错题换数字再练，答错归档 | 入口在错题本；9 类变体 + 正确性闸门 |
| G10 | 数据备份：导出/导入 JSON，堵住"卸载即丢" | 合并规则有 15 条回归断言 |

### 明确不做（Out of scope）

- **不申请任何权限**（当前 0 条）。拍照走系统 `ACTION_IMAGE_CAPTURE`，不碰 `CAMERA`。
- **核心链路不依赖网络**。断网、key 失效只影响拍照与讲解两块，其余照常。
- **不上架商店**。当前是 `debug.keystore` 调试签名。
- **不做多用户/云同步**。数据是单设备本地文件。

## 2. 三条不妥协的规矩（架构约束，改动前先读）

| 规矩 | 为什么 | 落在哪 |
|---|---|---|
| **答案必须本地算，模型不参与给数** | 模型给的讲解无法本地校验对错；"讲解和答案对不上"对小学生最致命 | `lib/core/rational.dart`（BigInt 分子分母，不用 double） |
| **每道题都要过正确性闸门** | 随机不等于随便：减法负数、除不尽、三边不成三角形、面积为零、多边形自交 | `lib/variant/generator.dart` 的 `VariantGate` |
| **验算三态，不许二态** | 没验算就亮绿勾是冒充正确 | `exact` / `unverifiable` / `mismatch` |

附带两条工程约束：
- **模型只输出数学关系，绝不输出坐标** —— 几何坐标一律本地求解器解析算出。
- **flutter_assets 里的 shader 必须是 impellerc 编译的 IPLR 产物**，不是 GLSL 源码。

## 5. 关键决策（ADR 摘要）

| 决策 | 选择 | 被放弃的方案 | 理由 |
|---|---|---|---|
| A1 数值表示 | `Rational`（BigInt 分数） | double | `0.1+0.2` 类误差会让本地与模型结果对不上，从而无法校验 |
| A2 讲解来源 | 本地模板 → 模型 Agent（本地复算兜底） | 纯模型讲解 | 模板与答案同源必然一致；模型讲解必须过闸门 |
| A3 相机权限 | 不申请，走系统 Intent | 申请 CAMERA + 自写相机页 | 维持"零权限"承诺 |
| A4 存储/分享 | MethodChannel 自写少量 Java | shared_preferences / share_plus | dex 干净、无插件注册失败风险 |
| A5 依赖解析 | 脚本抓 POM 递归展开 | 手写依赖清单 | 手写曾漏 5 个包，后果是"能装、一开就崩"且栈指不到根因 |
| A6 构建方式 | Python 手工编排 | `flutter build apk` / Gradle | 本机 Dart VM 无法管道 spawn 子进程（`CreateFile failed 231`） |
| A7 识别模型 | 默认 `deepseek-v4-flash`，备 `qwen3-vl-plus` | `gpt-image-2-token` | 后者是**画图**模型，chat 接口 500 `invalid_model`；主模型报 missing 时自动降级一次 |
| A8 体积 | 下载 NDK 用 `llvm-strip` 剥符号（2026-10-16 用户批准下载） | 自写 ELF 剥离器 | 官方工具处理节区重排更可靠；**绝不原地剥 SDK 缓存里的产物**（先复制再剥），要留符号时用 `--no-strip` |
| A9 备份合并 | 同 id 取"练得更多"的当底子：次数取大、**重要度取小**、到期取更晚 | 直接覆盖 / 取最新 | 重要度取小是关键：连对归零=已掌握，不能被旧备份拽回清单，否则清单变回耻辱墙 |
| A10 AI 出题 | 模型出题 + 本地复算 + 本地补全（归类/判重/夹紧难度），按 ≤3 道分批 | 纯模型出题（答案不可信）/ 纯本地模板（重复没新意） | 家长原话"大模型出新，系统补全"：新鲜度归模型，正确性归本地。分批是因为实测一次要 6~10 道会超时/烧光 token 预算 |
| A11 难度分档 | 基础（纯本地，不联网）/ 提高（一半 AI）/ 奥数挑战（AI 为主，≤6 道） | 只有一档 / 默认全 AI | 基础档零网络请求是核心承诺；AI 档有几十秒延迟与失败率，不能当默认路径 |
| A12 知识点匹配 | 年级优先于名字精确度 | "唯一同名就直接返回" | 曾因此把五年级长方形面积题标成"一上·认识图形·长方形"，家长看到的就是"五年级出一年级题" |
| A13 拍照判卷分工 | 模型只认字 + 本地判分 + 模型写批语，三步分离 | 模型一次既认字又判分 | 模型认错字就会顺手判错，孩子白背一个错题。判分必须由本地 `QuizAnswer.check` 定，用户还能在确认前改识别结果 |
| A14 衍生题分两路 | 能严格映射到变体模板的走本地（零联网、答案必对）；映射不上的才问模型，且**必须给验算式并本地复算一致** | 全部交给模型 / 全部本地 | 题库是**持久**的：错题本里错一次只丢一条记录，题库里躺一道错答案，孩子每次练都在巩固一个错误。所以模型那一路敢于"整道丢弃" |
| A15 题库与错题本分家 | `bank.json` 独立于 `wrongbook.json`，衍生题不参与 FSRS 调度与重要度统计 | 全部记进一个库 | 练习题混进错题本会把"要重点看 3 道"这类决策依据稀释掉 |
| A16 跨年级考点标签 | 匹配到别的年级的考点时只印考点名，不印年级前缀 | 照印 `p.path` | 三年级卷子上出现「五上 · 数学广角 · 植树问题」，家长看到的是"年级串了" —— 与 A12 同一个病根，这次治的是显示层 |
| A17 衍生题必须同**算法**（不只是同题型） | 本地衍生要带「算法结构」处方（`VariantShape`）：`rect` 分清面积/周长、`timesAs` 分清一步/两步、`add/sub` 分清加减、`shopping` 是找零两步；模板照结构出，闸门里再查一遍"要求减法出了加法就丢" | 只按题型名映射 | 真机上出过：面积错题衍生出**周长**题、减法错题衍生出**加法**题、两步倍数/找零衍生出**一步**乘法题。答案都没算错，但孩子练的是另一个考点，连对两次会在题库里留下假的"已掌握" —— 比不出题更糟。**判不出结构就返回 null 交给模型，不许猜** |
| A18 题库的落账依据「交卷快照」，不是输入框 | 交卷那一刻把作答抄进 `_answers`，落账读它；`QuestionCard.input` 传 null = "别动这个框"，传字符串（含空串）= "以它为准" | 落账时读 `TextEditingController.text` | 交卷后 `setState` 重建，共享组件的同步逻辑把 controller 里的作答清空了 → 落账读到全空串，练 3 道**一条痕迹都没记上**，而界面上完全看不出异常（只有把设备上的 `bank.json` 拉下来对账才发现）。界面状态不能当作事实来源 |
| A19 底部导航用 `IndexedStack` 保活 | 五个页面在 `initState` 里建一次，`body` 是 `IndexedStack(index:_index, children:_pages)` | 每次 `setState` 重建 `body` / 直接 `pages[_index]` | 家长原话"切个 tab 回来拍照页数据没了、练习页五年级变三年级"。直接索引也不行：那样离屏页面被摘出树、State 照样 dispose。`IndexedStack` 会保留全部子树的 State，只是不绘制 |
| A20 本地没收录该单元时，先不出题 | `wantAi>0` 且本地题库没覆盖 → `current` 先给空数组，`aiBusy=true`，明确写「本地题库还没收录，正在用 AI 按这个单元出题」；AI 失败也只在带一句「不是「$unit」的题」的前提下回落本地 | 本地题库没有就默默出同年级不相干的题 | 家长反馈"点出题秒出 6 道，可既不是 AI 出的也不是这个单元的"。**拿不相干的题充数比不出题更糟** —— 孩子以为自己练了那个单元。宁可多等十几秒并说清在等什么 |
| A21 变体闯关四层映射，判不出就异步问模型 | ① `localRecipeFor`（严格·带算法结构）② `variantKindFor`（宽松·看题型名）③ `variantRecipeByStem`（按题干推断：面积/周长/倍/找零/余数/分数）④ 兜底按年级**轮换**（原来是 `fallbackVariantKind(5)` 写死 `fracAddSub`，且 23 个题型里一半没有映射）；本地没有同算法模板的进 `_pending` 队列，用 `VariantAgent` 异步生成，全部失败才用轮换兜底并标注「同年级常规练习」 | 只按题型名映射 + 固定兜底 | 家长反馈"翻来覆去都是分数相加减"。第 ③ 层刻意**设了一堆 bail-out**（梯形/平行四边形/组合/格点/立体/展开/混合运算/植树/间隔/平均数/几分之几 → 返回 null），判不出结构就交给模型，不许猜 —— 猜错就是 A17 那类"答案对但练错考点" |
| A22 浮窗演算板做 App 内浮窗，不做系统悬浮窗；不做手写识别 | ① 悬浮球 + 面板挂在 `MaterialApp.builder` 的 Stack（Navigator 之上），五个 Tab 与 push 页面都能用；② 要手算切「画板」模式（四色笔/橡皮/撤销/清空），**不接识别**；③ 引擎 `lib/calc/expression.dart` 与 PC 端 `tool/floatcalc/engine.py` 逐条同口径（精确有理数 / 一步算式才出竖式 / 循环节重复两遍） | ① `SYSTEM_ALERT_WINDOW` 系统级悬浮窗 ② 上手写识别 | ① 系统悬浮窗要额外授权、平板分屏下行为不可控，家长端工具不该一上来就弹权限；② 识别错了比没有更糟 —— 家长会把识别错的数当验算结果；③ `/` 恒为除号、带分数在归一化阶段展开成 `(2+1/3)`，词法层只认一种数，两个载体才不会漂移 |
| A23 立体图形三条画法规矩（图形即答案的一部分） | ① **长方体 12 条棱必须画全**：剪影 6 条 + 正面 2 条 + 顶面右缘 1 条实线，被挡的 3 条（后左竖棱、底面两条）虚线 —— 曾经把左/右面的**对角线**当棱画、正面矩形没闭合；② **展开图判断题必须混入不可折的陷阱布局**（2×3 矩形、两片同侧），可折与否由 `CubeNetValidator` 三维折叠校验把关，求表面积的题只用可折布局；③ **虚线行为三个渲染器必须一致**（SVG/PDF/Canvas），Canvas 用 `computeMetrics` 截段实现 —— 曾经 App/PDF 漏了虚线分支，隐藏棱全画成实线 | ① 只画剪影 + 两条对角线 ② 判断题池子全是可折布局（答案永远"能"）③ 各渲染器自行其是 | ① 家长看到"图和题面对不上"；② 孩子无脑答"能"就能全对，题目白出；③ 同一份 `FigureScene` 三个后端，虚线是语义（被挡住），不是装饰 |

## 7.6 M11 明细（2026-10-16 家长反馈驱动）

家长提了两条："这个布局不合理，看看怎么改一下" + "我需要有个判卷子的 AI Agent，
出的题能根据照片进行判断"。

### ① 练习页布局重做

**现象**（截图）：蓝色头部占近半屏 —— 年级两行 chips + 难度 chips + 两个下拉 +
大全宽"换一套题" + PDF 按钮；题卡被挤成一条；键盘一弹连题都看不见。

**修法**：头部从 5 行压到 3 行约 120px（标题+年级胶囊 / 难度 chips+PDF 图标 /
知识点+题数+换一套工具栏），题卷区拿回主体空间；年级/知识点/题数改走底部弹层
（比内嵌下拉省高度、选项看得清）；作答点中题卡后 350ms 自动滚进键盘上方可见区；
底部双按钮平权：「拍照判卷」（纸上作答）+「提交批改」（屏上作答）。

### ② AI 判卷（`lib/ai/grader.dart`）

分工三步分离，每步只干一件事：

| 步骤 | 谁干 | 干什么 |
|---|---|---|
| 认字 | 模型（vision） | 把手写答案读成文本；认不出留空 + 注明，**不许猜**；不抄印刷体题干 |
| 判分 | **本地** `QuizAnswer.check` | 规范化比较（全角半角、单位剥离、余数写法、小数尾零、数值容差） |
| 批语 | 模型（chat） | 只给本地判错的题写一两句批语；不提正确答案 |

**为什么判分不交给模型**：模型认错字就会顺手判错 —— 把 `79` 认成 `96`、
把 `7……5` 认成 `7.5`，孩子白背一个错题。判分在本地，认错字会被逮住；
而且确认批改前识别结果可改，改完本地实时重判。

**认不出不判错**：空答案或字迹不清一律标「未识别」—— 没看清就判错是冤枉孩子。
未识别的题在练习页显示为琥珀色"未识别"卡，不记入错题本。

**实测**（合成手写答卷，Ink Free 手写体 + 逐字旋转抖动）：
3 题判对（含余数 `7……5`）、1 题认出手写 `90` 本地判错并得批语、
1 题空白未识别。认卷 2.6 s / 1.3k tokens。离线回归 25/25。

**模拟器验收**（2026-10-16，x86_64 包装机，用 PIL 按当页卷子合成匹配的手写答卷）：

| 验收项 | 结果 |
|---|---|
| 新布局 | 头部三行约 120px（原近半屏）；一屏可见两道完整题卡（原一道被挤成条） |
| 键盘避让 | 点作答框 → 键盘弹起 → 当前题完整滚入可见区，底部双按钮不被挡 |
| 判卷全流程 | 相册选图 → 认卷 → 逐题显示（对 3 / 错 1 / 未识别 2）→ 确认批改 → AI 批语 |
| 本地判分权威 | 手写错答案 `67`（应为 61）被本地判错；模型认对认错都不影响判定 |
| AI 批语质量 | "你把减法先算了，碰到乘法和加减混在一起时，要先算乘法哦。下次动笔前先圈出要先算的那一步，你一定能算准！"（点错因、鼓励、不泄露答案） |
| 未识别安全降级 | 空白题与图底部未读到的题标「未识别」琥珀卡，不判错、不进错题本 |
| 结果回显 | 回练习页：识别答案填入输入框、对错图标、讲解展开；底部「答对 X / 已判 Y（Z 题未识别）」 |
| 错题归档 | 两轮判卷后错题本 9 → 14 条（1 + 4 道错题全部进复习队列，角标同步） |
| 题卷不匹配的边界 | 拿 A 卷的照片判 B 卷：按题号硬套、全判错 —— 每张卡片都显示题干摘要供核对，文档已列此边界 |

**验收中发现并修掉的显示缺陷**：判卷回到练习页后输入框是空的 ——
外部 controller 没跟 state 同步（verdict/讲解都对，但家长看不到"认出了什么"）。

### ① 判卷之后自动衍生（`lib/ai/derive.dart`）

两条路，**本地优先**：

| 路 | 触发条件 | 答案怎么保证 |
|---|---|---|
| 本地变体模板 | 错题题型能映射到一个模板，**且算法结构判得出来**（`localRecipeFor`：加减、乘法、倍的认识、有余数除法、长方形面积或周长、三角形、圆面积、单位换算、购物找零） | `VariantGenerator` 按结构改数字 + `Rational` 精确算，零网络 |
| 模型按原题干出 | 本地没有同算法模板（混合运算、植树/间隔、平均数、梯形、平行四边形、圆周长、组合图形、格点图形、立体图形/展开图/圆柱、求一个数的几分之几、AI 应用题） | 模型必须给 `equation`，本地复算必须一致，否则整道丢弃 |

**本地这条路的判据只有一条：孩子做这道衍生题时用的算法和原题一样吗？**
而且**光看题型名不够** —— 一个题型里藏着几种算法（`rect` 有面积有周长、
`timesAs` 有一歩有两步、`sub`/`add` 是两种运算、`shopping` 是两步找零），
所以处方里要带**算法结构**（`VariantShape`，见 A17）。名字听起来相关不算：
「混合运算」不映射到加减模板（考的是运算顺序）、「植树」不映射到单价×数量
（考的是段数与点数）、「求几分之几」不映射到同分母分数加减 —— 这些走模型那一路；
没配 key 时如实说"暂时造不出"，不出不相干的题充数。

**映射为什么不用「变体闯关」那套年级兜底**：衍生题挂在**一道具体错题**下面，
出成不相干的题型比不出题更糟；而「变体闯关」是家长主动点的按钮，点下去必须有反应。
所以现在是三个函数：`localRecipeFor`（严格，带结构，给衍生题）、
`variantKindFor`（宽松，只看题型名，给变体闯关）、`fallbackVariantKind`（年级兜底）。

**模型那一路的五道闸门**（`DeriveAgent._accept`）：题干要配图 → 丢；
没给验算式 → 丢；算式解析不了 → 丢；本地复算与模型自报不一致 → 丢；
非有限小数 → 丢。理由是题库**持久**：错题本里错一次只丢一条记录，
题库里躺一道错答案，孩子每次练都在巩固一个错误。

**本地优先也是性能设计**：有模板的题根本不进 prompt；没模板的错题攒成**一次**
请求批量问模型（最多 6 道原题），不是一道一次。

**后台跑**：`deriveFromWrong()` 用 `unawaited` 发出，判卷结果不等它；
判卷页多一条状态条（`_DeriveStatus` 用 `ListenableBuilder` 单独监听 AppState），
显示"错题 2 道 → 衍生题 6 道已进题库（其中 3 道由 AI 现场出）"。

### ② 题库（`lib/store/bank.dart` + 错题本页第二段）

- 错题本页改成两段：`错题本`（欠账清单，带 FSRS）/ `衍生题库`（补给站，只有"过关没"）；
- 过关判定 = **连对两次**（`BankEntry.passStreak = 2`）：对一次可能是顺着上一题顺出来的，
  三次则练到记住数字而不是方法；过关只升不降；
- 练衍生题（`bank_practice_page.dart`）：答错的进错题本并进复习队列，答对的只记在题库
  （刻意与练习页不同 —— 衍生题是补给，不该把错题本撑大）；
- 题库 id 由规范化题干的 **FNV-1a** 算出（不用 `String.hashCode`：它只保证同一次运行内稳定，
  跨版本一变，升级后同一个题会被当成新题再入账）；
- `bank.json` 独立于 `wrongbook.json`，不参与 FSRS 调度与重要度统计（见 A15）。

### ③ 顺带修掉的显示缺陷：三年级卷子上出现「五上」前缀

**现象**：M12 验收时在练习页看到三年级卷子上标着「五上 · 数学广角 · 植树问题 · 间隔问题」
和「一下 · 数与代数 · 认识人民币 · 简单购物」。

**根因**：A12 给 `KnowledgeIndex.match` 留的"最近年级保底" —— 当前年级找不到同名考点时
退到最接近的年级，于是把那个年级的前缀一起印了出来。

**修法**（`lib/quiz/generator.dart` 的 `Util.kpPath` / `kpCode`）：跨年级匹配时只印考点名，
不印年级前缀；考点编码一并留空（不把三年级的题记到五上的编码上）。
新增体检工具 `tool/kp_label_check.dart`：六个年级各抽 72 道，共 **432 道题标签，0 处跨年级**。

### ④ 模拟器端到端验收时逮到的两个真 bug（2026-10-17）

这两个都不是"想出来的风险"，是**装到模拟器上真点一遍**、再把设备上的 json 拉下来对账才暴露的。
共同点：界面上完全看不出异常，数据已经错了 —— 所以验收不能只看截图。

**bug 1：衍生题换了算法**（记在 A17）

一次判卷 4 道错题 → 衍生 12 道，全部 `origin=local`，但：

| 源题 | 当时衍生出 | 问题 |
|---|---|---|
| 长方形**面积** 8×5 | 长 12 宽 4 的**周长** | 3 道里 2 道换了公式 |
| 不退位**减** `731 − 463` | **573 + 652** | 减法变加法 |
| **倍的认识** `3+3×2`（两步） | 每盒 38 支买 3 盒（一步乘） | 少一步 |
| **简单购物** `60−6×4`（两步找零） | 一支 28 元买 11 支（一步乘） | 少一步 |

答案本身都没算错，所以原来那套"只验答案对不对"的闸门一道也拦不住 ——
但孩子练的是另一个考点。修法：处方带结构、模板照结构出、闸门里加"结构是命令"的检查、
判不出结构退回模型。回归 `test/derive_shape_manual.dart`（79 条，真实题干派生 2703 道题）。
修后同一台设备再跑同一流程：减法题全出减法（546−233=313 ✓）、找零题仍是两步找零
（5 支×6 元付 50 找回 20 ✓）、有线除法带余数（54÷7 = 7……5 ✓）。

**bug 2：练完衍生题，题库里一条痕迹都没记上**（记在 A18）

「结果 2/3」显示得好好的，点「完成（错的进错题本）」也正常返回，
但 `bank.json` 的 `savedAt` 一动没动、三个题都还是「没练过」。
根因：交卷后 `setState` 重建，`QuestionCard` 把外部 `TextEditingController`
按 `input`（当时传的 null，被当成空串）同步了一次 —— **把孩子的作答清空了**，
于是落账读到全空串，`if (input.isEmpty) continue` 逐条跳过，静默什么都不记。
顺带一个可见症状：交卷后输入框里的答案消失，孩子看不到自己写了什么。
修法见 A18；修后实测：单题连对两次 → `attempts=2 / streak=2 / passed=true`，
界面「未过关 12 → 11」并标「已过关」；故意答错的题进错题本（25 → 26，`kind=derived`）。

### ① 做了什么

## 10. Agent 流程（四个 Agent，一条规矩）

四个联网 Agent 全部遵守同一条规矩：**模型只产出"数学关系与文字"，答案与对错一律本地重算**。
所以每个 Agent 的形状都一样：prompt → 模型输出 → 本地闸门 → 本地复算 → 不合格带原因重发一次 → 仍不符如实亮红牌。

| Agent | 入口 | 模型负责 | 本地负责（权威） | 不合格怎么办 | 实测 |
|---|---|---|---|---|---|
| **讲解 Agent** `lib/ai/explain.dart` | 练习页点「讲解」 | 分步骤 + 最终答案 + 一条可验算 `equation` | `Rational` 从 equation 复算；步骤 ≥2、答案含数字 | 少于 2 步或复算不符 → **带原因重发一次**；仍不符标 `mismatch`，不假装成功 | 三题全部一次通过（6.5 / 2.1 / 2.8 s） |
| **识题 Agent** `lib/ai/vision.dart` | 拍照 / 相册选图 | 把手写或印刷题干读成文本，**只许抄不许解**；认不出留空并注明，不许猜 | 题干可改；家长确认后才进下一步 | 模型不守 JSON → 兜底成一步并标「不完整」，不抛异常 | 合成答卷 5 题，认卷 2.6 s |
| **判卷三步** `lib/ai/grader.dart` | 拍照判卷 | ① 认字（vision）② 只给判错的题写批语，**不提正确答案** | **判分由本地 `QuizAnswer.check` 定**（全角半角、单位剥离、余数写法 `7……5`、小数尾零、数值容差） | 认不出 → 标「未识别」不判错（没看清就判错是冤枉孩子） | 5 题：3 判对 / 1 认出手写 `90` 判错得批语 / 1 未识别 |
| **衍生 Agent** `lib/ai/derive.dart` | 判卷确认后（`unawaited` 后台） | 只给**没有本地模板**的错题出同类题，必须给 `equation` | ① 先用 `localRecipeFor` 从题干认**算法结构**，判得出就走本地模板（零联网）；② 模型那一路五道闸门 + 复算一致 | 要配图 / 没验算式 / 算式解析不了 / 复算不一致 / 非有限小数 → **整道丢弃**；本地判不出结构 → 返回 null 交模型，不许猜 | 4 道错题 → 12 道入库（本地毫秒级）；没模板的攒成一次请求批量问（≤6 道） |
| **出题 Agent** `lib/ai/quizgen.dart` | 练习页选「提高 / 奥数挑战」 | 出完整应用题 + 2~4 步讲解 + 可验算 equation | 归类 / 判重 / 按档位夹紧难度 + 答案复算 | 与衍生 Agent 同一套闸门；按 ≤3 道分批（一次 6~10 道会超时） | 五年级奥数 4 道、六年级奥数 4 道、五年级图形运动 4 道，闸门 0 误杀 |

**共同点（也是这套设计唯一的核心）**：模型永远在"提建议"，本地永远在"做决定"。
所以模型答错不会变成孩子的错答案 —— 它只会被丢掉，或者被标成"没验算"。
