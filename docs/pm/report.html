01一页看懂

三句话讲完这个东西是什么。

题是本地出的，答案也是本地算的

23 个题型工厂，每题过正确性闸门；数值全走 Rational 精确有理数，不用浮点。 联网只是增强项 —— 断网、key 失效，练习/复习/导出照常。

模型只讲不算，答案一律本地复算

四个 Agent 输出的验算式由本地重算，对不上就带着原因打回重做一次， 仍不符亮红牌。验算三态，没验算就不亮绿勾 —— 不冒充正确。

错题会自己找上门，也能打印出来

FSRS 间隔复习，只出到期的题；重要度会衰减（连对 3 次归零）， 不会变成耻辱墙。随时导出 A4 矢量 PDF，图形是真矢量不是截图放大。

04判卷到衍生题库：最近补上的这一环

家长原话："卷子打印出来了，根据拍照卷子判卷，判卷结束后把错题引入错题本， 同时生成衍生题，衍生题进题库。" 这条链已在模拟器上从头点到尾。

衍生的两条路，本地优先

路什么时候走答案怎么保证
本地变体模板错题题型能映射到模板，且算法结构判得出来（加减、乘法、倍的认识、有余数除法、长方形面积或周长、三角形、圆面积、单位换算、购物找零）按结构改数字 + Rational 精确算，零联网、毫秒级，有模板的题根本不进 prompt
模型按原题干出本地没有同算法模板（混合运算、植树/间隔、平均数、梯形、平行四边形、圆周长、组合图形、格点、立体图形/展开图、求几分之几、AI 应用题）模型必须给 equation，本地复算必须一致，否则整道丢弃；没配 key 时如实说"暂时造不出"，不出不相干的题充数

「同类」是同到算法，不是同到题型名

这是这一轮真正学到的东西：一个题型名底下藏着好几种算法。 答案都没算错，但孩子练的是另一个考点 —— 比不出题更糟，因为连对两次会在题库里留下假的"已掌握"。

源错题当时衍生出（真机实测）问题现在
长方形面积 8×5长 12 宽 4 的周长换了公式处方带 rectArea，只出面积
不退位减 731−463573 + 652减变加处方带 sub，闸门见加法就丢
倍的认识 3+3×2（两步）每盒 38 支买 3 盒（一步乘）少一步题干含「一共」→ mulThenAdd
简单购物 60−6×4（两步找零）一支 28 元买 11 支（一步乘）少一步题干含「找回」→ mulThenSub
判不出结构就交给模型，不许猜。所以「求几分之几」不再映射到同分母分数加减（那是另一种算法）， 「混合运算」不映射到加减模板（考的是运算顺序），「植树」不映射到单价×数量（考的是段数与点数）。 回归用真实出题器的 1560 道题干派生 2703 道题，逐道校验结构 + 用独立于生成器的公式复算答案。

这一轮逮到的两个真 bug（都是只看截图看不出来的）

① 衍生题换了算法

界面一切正常，12 道衍生题全部 origin=local，但四类的算法全错。 根因是只按题型名映射。修法：处方带算法结构（VariantShape）、 模板照结构出、闸门里再查一遍"结构是命令，不是建议"。

② 练完题库一条痕迹都没记

「结果 2/3」显示正常，点完成也正常返回，但 bank.json 的 savedAt 一动没动。 根因：交卷后 setState 重建，共享组件把外部 controller 按 input=null 同步了一次，把孩子的作答清空了 → 落账读到全空串，静默跳过。 修法：null = "别动这个框"；落账改读交卷快照。

所以验收不能只看截图。这两个 bug 的共同点是"界面看不出异常，数据已经错了"， 只有把设备上的 bank.json / wrongbook.json 拉下来对账才暴露 （savedAt 变没变是最快的判据）。修后实测：单题连对两次 → attempts=2 / streak=2 / passed=true，界面「未过关 12 → 11」并标「已过关」； 故意答错的题进错题本（25 → 26，kind=derived）。

v1.3：浮窗演算板（2026-10-17 家长提出，当日闭环）

家长原话：「能不能做个浮窗演算用？」→「我的想法是在手机上弹出一个画板可以自己运算，适用于平板」。 PC 端先交付了 tkinter 版（tool/floatcalc/，系统置顶窗口），v1.3 是手机/平板版。

决定做法被放弃的方案理由
载体可拖拽悬浮球 + 演算面板，挂 MaterialApp.builder 的 Stack（Navigator 之上），五个 Tab 与 push 页面都能用SYSTEM_ALERT_WINDOW 系统级悬浮窗系统悬浮窗要额外授权、平板分屏下行为不可控；家长端工具不该一上来就弹权限
两个模式「计算」（输入即算 + 小键盘 + 历史）+「画板」（四色笔/橡皮/撤销/清空）上手写识别识别错了比没有更糟 —— 家长会把识别错的数当验算结果
平板适配最短边 ≥ 600 切宽布局（左输入键盘、右结果竖式），手机窄布局，同一份代码另做一套平板 UI主界面仍锁竖屏（竖式/几何横屏会被压扁），平板竖屏宽度已够宽布局用

同类题✅简单题本地生成、复杂题模型生成，两边答案都本地复算，不符就丢
AI 出新题✅难度三档：基础（本地，零联网）/ 提高（一半 AI）/ 奥数挑战（AI 为主）。模型出应用题，答案本地复算；最近题干避重。实测五年级奥数 4 道、六年级奥数 4 道、五年级「图形的运动（三）」4 道，闸门 0 误杀、答案手工复核
AI 判卷✅拍手写答卷 → 模型只认字、对错由本地判分规则定、模型只写批语。认不出标「未识别」不判错。模拟器实测：4 题判对、手写错答案被本地逮住并得针对性批语、空白题未识别；错题自动进复习队列
错题衍生题库✅判卷确认后为每道错题自动造 3 道同类题，进「错题本 → 衍生题库」。本地优先：题型能严格映射到变体模板的走本地（零联网、答案必对）；映射不上的才问模型，且必须给验算式并本地复算一致，否则整道丢弃（题库是持久的，错答案会被反复练）。练题连对两次算过关，答错的进错题本。整链模拟器实测：4 道错题 → 12 道入库 → 练习记痕迹 → 连对两次「已过关」（未过关 12→11）→ 答错进错题本（25→26）
衍生题「同算法」保证✅本地衍生带「算法结构」处方：面积≠周长、减法≠加法、两步≠一步、"求几分之几"≠分数加减。判不出结构就交给模型，不许猜。回归用真实出题器的 1560 道题干派生 2703 道题逐道校验（结构与独立复算），79 条断言全过。真机上就靠这个逮住了 4 类"答案对但练错考点"的衍生题
运行记录✅调用统计 + 学习侧统计（错题数/今日到期/正确率）+ CSV 导出
变体闯关✅错题本一键「变体闯关」：同类题换数字，答案本地算，答错自动归档（模拟器实测错题本 3 → 9）
数据备份✅导出带时间戳 JSON（分享到微信/邮件/网盘），导入走系统选择器并与现有记录合并；合并规则 15 条回归断言
体积优化✅NDK llvm-strip 剥掉引擎调试符号：172 MB → 26.3 MB，模拟器启动正常（+1.57 s）
iPhone 可用✅Web 版做成 PWA：iPhone 用 Safari 打开 →「添加到主屏幕」→ 全屏图标，即装即用、共用同一份内核。iOS 工程骨架与 Swift 通道也已备好，拿到 Mac 跑 build_ios.sh 即可出 .ipa

反对意见结论处理
模型没给验算式，界面却亮「已本地验算」绿勾确认缺陷验算改三态，没验算就是没验算
要求步骤全面，但模型只给一步也照单全收确认缺陷≥2 步 + 有答案 + 答案含数字，不完整体打回重做
同类题只能看不能练，错了不进错题本确认缺陷生成的题转成可作答题，能归档、能进复习队列
没相机 / 用户取消时点了没反应确认缺陷明确提示并引导「试试从相册选」
管理员只有接口日志，看不到孩子练得怎样确认缺陷加学习侧统计 + CSV 导出
照片会无限堆积确认缺陷只保留最近 20 张
生成的题会不会出负数、循环小数已覆盖本地出题保证非负与有限小数，用例已断言
模型乱答（不按 JSON）会不会崩已有兜底整段话兜底成一步并标「不完整」，不抛异常

风险等级对策
体积 172 MB，引擎未 strip已解决NDK llvm-strip 剥符号 → 26.3 MB；排查 native 崩溃时可 --no-strip 出带符号包

iOS 无法在本机构建已缓解Web 前端 + 局域网模式：iPhone Safari 打开「观感验收」页，同一内核同一套图形
