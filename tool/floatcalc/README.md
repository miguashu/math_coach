# 浮窗演算器（Windows 桌面小工具）

家长随手验算用：一个置顶小浮窗，敲个算式就出**精确结果**和**小学竖式**。
是 math_coach 的配套桌面工具，不属于 App 构建产物，纯本地、不联网、不装依赖
（只用系统 Python 自带的 tkinter）。

## 怎么起

- 桌面双击 `浮窗演算.bat`（`C:\Users\Lenovo\Desktop\`），或本目录的 `start_float_calc.bat`；
- 命令行：`python app.py`（python 用系统那个
  `C:\Users\Lenovo\AppData\Local\Programs\Python\Python310\python.exe`，
  WorkBuddy 托管的 3.13 没有 tkinter，起不来 GUI）。

启动后窗口直接亮相在屏幕右下角。**Ctrl+Alt+Q** 随时唤出/收起；
Esc 或焦点移出别的窗口也会自动收起（演算时不想被挡视线）。

## 长什么样 / 点下去发生什么

| 操作 | 结果 |
|---|---|
| 输入 `3.6+4.8` | 大结果 `8.4`，下面跟小数点对齐的竖式，边打字边算不用回车 |
| 输入 `58÷7` | 精确值 `58/7`，副行同时给 `8.285714…（循环小数）`、`= 8又2/7`、`= 8……2`，竖式是长除法带余数 |
| 输入 `2又1/3+1/2` | 带分数直接参与运算，结果 `17/6` + 带分数 `2又5/6` |
| 输入 `80×50%` | 百分号照常算，`40` |
| 复制一段算式再按热键 | 剪贴板里「像算式」的内容自动带进输入框并算出结果 |
| 点大结果 | 复制结果到剪贴板 |
| 点历史小条 | 把那条算式填回输入框 |
| 点标题栏「钉」 | 进入点击穿透 + 不抢焦点模式，贴着屏幕不挡操作；再按热键解除 |
| 拖标题栏 | 移动窗口，位置记住在 `floatcalc_config.json` |

## 背后靠什么算出来（engine.py）

- **精确有理数**：全程 `fractions.Fraction`，`0.1+0.2` 就是 `0.3`，不吞浮点误差。
- **递归下降解析**（不用 `eval`）：支持 `+ - × ÷ * / ^ ()`、小数、分数 `a/b`、
  带分数 `2又1/2`、`几分之几`（`2分之1`）、百分号后缀、隐式乘（`2(3+4)`）、
  全角字符（`３.６＋４.８`、`×÷（）＝％`）。
- **小数三态**：有限小数给精确值；循环小数检测循环节并标注（`0.33…` + `循环节 3`）；
  整数除法给出 `商……余数`。
- **竖式只对「一步算式」出**（两个数字字面量的 `+ - × ÷`）：多步算式只给结果，
  不假装有竖式。加减小数点对齐、乘法列部分积（带小数时附
  「共几位小数、从右起数几位点小数点」的说明，人教版口径）、除法长除法逐步乘积余数。

## 自检（都不开真窗口也能跑）

```bash
python engine.py            # 引擎自检：归一化/精确性/优先级/错误/小数/三种竖式
python app.py --ask "58÷7"  # 命令行算一个，打印完整结果块
python app.py --selftest    # 环境自检：DPI/屏幕/热键可注册性 + 引擎
python app.py --smoke       # 开窗 1.4 秒自截屏自退，产出 smoke.png
```

## 已知边界（刻意没做）

- 长除法竖式只接整数（被除数 < 10^8、除数 < 10^4）；分数相除没有小学竖式，
  `1÷3` 只给 `0……1` 和精确值。
- 乘法竖式上限 7 位 × 5 位，超了只给结果。
- 减法结果为负时，竖式按原式排，结果行带 `-` 号（不做「大减小」换位）。
- 指数只接受整数；`0` 的负数次方报错。
- 只做了 Windows（tkinter + 全局热键都是 Win32 API）。

## 文件

| 文件 | 作用 |
|---|---|
| `engine.py` | 演算引擎：归一化/解析/求值/格式化/竖式 + 自检 |
| `app.py` | 浮窗 GUI：热键线程、窗口样式、剪贴板预填、历史、三种自检开关 |
| `start_float_calc.bat` | 启动器（纯 ASCII + CRLF，cmd 代码页下不会乱码） |
| `make_launcher.py` | 重新生成启动器（本地 + 桌面各一份） |
| `floatcalc_config.json` | 窗口位置 / 热键 / 透明度 / 剪贴板开关 / 历史 |
| `run.log` | 运行日志：热键注册失败、剪贴板读取、每次 show 的预填决策 |
